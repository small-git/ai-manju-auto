# Manhua Workbench Design System

Source: UI/UX Pro Max `--design-system`

## Style
- Soft UI Evolution + Glassmorphism + Bento hierarchy
- Soft multi-stop page gradients for depth
- Layered elevation via soft shadows (not neon glow)

## Colors
| Role | Token | Value |
|------|-------|-------|
| Page gradient | --grad-page | #eef3f9 → #e8eef6 → #f3eef8 → #eef6f4 |
| Accent | --accent | #3b6fd4 |
| Ink | --ink | #1a2332 |
| Muted | --muted | #6b7789 |
| OK / Danger | --ok / --danger | #1f9d6a / #d45353 |

## Typography
- Display: Noto Serif SC
- Body: Noto Sans SC

## Hierarchy
1. Page mesh gradient (atmosphere)
2. Glass sidebar (blur + translucent)
3. Cards (white gradient + soft shadow-2)
4. KPI / still thumbs (stronger visual weight)
5. Meta chips (quiet secondary)

## Avoid
- Neon / vaporwave / memphis flash
- Glow-heavy accents
- Pure black OLED cyber look
